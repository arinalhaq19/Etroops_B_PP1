# Manajemen Daftar Pelanggan
Program yang dirancang yang bertujuan untuk menajemen daftar pelanggan skala kecil dan menengah. Program ini diharapkan dapat membantu dalam pengelolaan data pelanggan secara cepat dan teroganisir.

# Fitur Program
* Tambah : Bisa menambah data pelanggan.
* Tampil : Menampilkan seluruh daftar pelanggan beserta total pelanggan
* Cari : Bisa mencari data pelanggan berdasarkan id.
* Edit : Bisa mengubah data pelanggan.
* Hapus : Bisa menghapus data pelanggan.
